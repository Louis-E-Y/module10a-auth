1. In my own words, authorization and authentication differ in the same way that just because you are allowed in somewhere, it does not mean you own the place. Just because your ticket is valid and they let you on the plane does not mean youre allowed to sit anywhere you like or go in the cockpit. Different valid users have different rights/ access levels.
2. Passwords are hashed because this way even if they are stolen, they are stored in a secret language that only your own login tool knows how to RECREATE, not even decipher. Therefore nobody can ever reverse the process, and the only way passwords are actually verified is that the user input is scrambled again and compared to the stored scramble/ hash.
3. The login and register routes are registered by Laravel Fortify, and the command which lets you see them (all routes) is php artisan route:list.
4. The auth middleware puts another virtual bouncer in front of the door/ route and sees if the user is allowed in, and if not then the user will be sent back where they came from or back the way they were headed. If a logged out user hits a page that requires login, the user is redirected to the login page.
